HOW TO ADD YOUR GROQ API KEY
==============================

OPTION 1 — Enter key in the app UI (easiest):
  Open the app → AI Chat tab → "Set API Key" → paste gsk_... → Save
  (stored in your browser localStorage, sent with every request)

OPTION 2 — Vercel environment variable (recommended for production):
  Vercel dashboard → Your project → Settings → Environment Variables
  Add:  GROQ_API_KEY = gsk_xxxxxxxxxxxxxxxx
  Then Redeploy.

OPTION 3 — Hardcode in source (quick test only, don't commit to public repos):
  Open: app/api/process/route.ts
  Find:  || 'YOUR_GROQ_API_KEY_HERE'
  Replace with your actual key string.

Get a FREE Groq key at: https://console.groq.com

DEPLOYMENT STEPS:
  1. npm install
  2. Push to GitHub
  3. vercel.com → New Project → Import repo
  4. Add GROQ_API_KEY in Environment Variables
  5. Deploy!
